# 功能边界

下表区分代码中包含的能力和本候选已经验证的范围。旧私有部署的验收结果不能自动转移给新用户的安装。

| 能力 | 新安装如何看待 |
|---|---|
| 普通文字、HTML、MarkdownV2、消息编辑 | 基础入口；此前在相同后端代码上检查本机HTTP及模拟Telegram回执，真实Bot待验收 |
| 图片、视频、文件、音频、GIF、语音、贴纸 | 包含实现及自动测试；此前模拟图片派发，其他媒体不能称为新部署实发通过 |
| 标题、表格、公式、正文穿插图片 | 包含Rich编译器；结构可离线检查，发送需独立配置及客户端验证 |
| 正文按钮、音视频混排、群内渐进编辑、私聊草稿 | 有二期实现和测试；按功能启用，不能仅凭开关认定可用 |
| 自定义确认 / 停止按钮 | 需特定用户、回调订阅及存储，保留权限校验 |
| Telegram原生草稿停止 | 实验；原有真实点击验收未通过，不承诺稳定 |
| 模型流式生成 | 通用接口与模拟分片；没有内置真实模型服务 |
| 多Bot、个人账号、Business、支付、管理能力 | 部分为实验、默认关闭；启用前逐项审阅权限和流程 |

这不是自动日报或自动营销服务。不会自动注册webhook、导入账号、应用迁移或启动生产定时任务。不要把工具目录中出现某项能力理解为已授权、已配置或已完成真实验收。
